# Diary Maintenance

## When diary.md exceeds ~500 lines:

1. Create monthly archive folder: `diary/2026-01/`
2. Move entries older than 7 days to: `diary/2026-01/2026-01-DD.md`
3. Keep most recent 7 days in main diary.md
4. Add index entry at top of archived month

## File Structure:

```
diary/
├── diary.md              # Active diary (recent 7 days)
├── 2026-01/              # January 2026 archive
│   ├── index.md          # Summary of the month
│   ├── 2026-01-24.md     # Daily entry
│   └── 2026-01-25.md     # Daily entry
└── 2026-02/              # February 2026 archive
    └── ...
```
